Gameplay

How to play

  1. Choose your settings

    Open BrainBlitz on Android or Telegram. Choose a category, a question timer, and the total number of players.

  2. Find a match

    Join the queue. Android and Telegram players on the same server can match when their category, timer, and game size are the same.

  3. Beat the clock

    See whether your answer was correct as soon as you submit it. Review the correct answer at the end of each round and the final standings after the match.

Architecture

Under the hood

Five Go services run the game. Kafka carries events between services, and both clients receive live updates over WebSocket.

The stack uses PostgreSQL for accounts and questions, MongoDB for game sessions, and Redis for queues and game state.
